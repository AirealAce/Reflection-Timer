# Reflection Timer desktop 4.2.47

This is the primary accessible desktop app. Build `ReflectionTimer.Desktop/ReflectionTimer.Desktop.csproj`; run `ReflectionTimer.Tests` and its `ui.cjs` browser checks.

The HTML/WebView2 interface retains the four original views and uses the shared C# timer and Sheets engine. Existing installations keep their encrypted desktop profile and connection automatically. Explicit named test profiles remain isolated.

Focus mode offers a first-row Use focused window/tab/tab group choice in each category. These choices capture the actual foreground target on start/resume, stay dynamic in the saved profile, and can all be checked together with Multiple Targets. Mode switches and settings changes do not recapture; after restarting the app, start or pause/resume to capture again. Focus mode works for Timer and Stopwatch, with accessible window/browser-tab/tab-group tables and independent Settings → Audio controls. Multiple Targets keeps checked selections across categories; any selected target counts as focused. Optional Idle for alerts on keyboard/mouse inactivity (20 seconds default). Both options start unchecked, with Focus off, a five-second away delay and the existing Battle (Trainer) MP3. Ctrl+Enter and Ctrl+S save the chooser from any control. Single choices show app name, tab # - tab name, or group name; multiple choices show their categories. Tab groups use English Chrome/Edge accessibility labels and their current members; duplicate and unnamed groups retain separate identities. Run `ReflectionTimer.Tests --focus-mode` and `ReflectionTimer.Tests/focus-mode.cjs` for focused checks; `--focus-target-scan` reads the current window/tab/group accessibility providers and reports counts without target names.

The target button shows **Window**, **Tab**, or **Tab Group** in bold above the saved name and keeps the active theme color even when Focus is off. Its name follows the picker: windows start with app/window information, while tabs start with app/tab information before the window context. The current tab in the most recent readable browser window follows Use focused tab and is marked **(current tab)**. Duplicate identities are removed, without merging distinct tabs that share a title. Refresh updates the current marker while retaining a still-available saved target as the selected choice. Existing saved selections use the same display without choosing them again. Long names stay on one line, with their full text available to screen readers and in the hover tooltip. In the picker list, Enter, Space, double-click, and **Use selected target** perform the same save; arrow keys navigate without saving. Confirmation returns focus to the opener, blocks duplicate requests while saving, and keeps a failed selection open for retry.

Use `install.ps1` for a per-user install with backups, or `package-release.ps1` to create a self-contained verified ZIP. Packaging does not publish. The old native desktop source is preserved in `../inaccessible-version-useless/desktop`.

Open START-HERE.html for setup. See HOTKEYS.md for shortcuts and Sounds/README.md for the bundled MP3 defaults.
