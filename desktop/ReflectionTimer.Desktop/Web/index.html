    How delivery retries work

    With the updated receiver, temporary upload failures retry automatically using the same entry ID, with increasing delays up to five minutes. Partial writes, legacy uploads and changed receivers still need review. After eight upload attempts, automatic retries stop. Temporary connection failures retry with delays up to five minutes. Setup or access errors wait for you to review the connection and retry.

    Keyboard shortcuts

    Ctrl+Tab switches to the next App tab. Ctrl+Shift+Tab switches to the previous tab. Both wrap around and work from inputs; an open dialog keeps focus.

    Space or Ctrl+Enter starts, resumes, or pauses the timer anywhere in Compact or Time-only view, like Enter in a duration field. In Settings, Ctrl+Enter or Ctrl+S saves all pending settings from any focused control or page text. In a reflection prompt, Ctrl+Enter or Alt+S sends the response and ends its own session early if it is still running or paused. Both skip when all reflection and reason fields are completely empty. Ctrl+S saves the draft locally and closes. Alt+Enter sends a check-in without ending the timer.

    Ctrl+R resets the timer to the duration inputs and refreshes the focused view, including session-end prompts. The timer becomes ready to start. Your App tab, Compact or Time-only mode, and reflection drafts are retained. Save unfinished settings before refreshing.

    Audio

    Disruptive stops other app audio. Assertive lowers other app audio to 25% until it finishes. Polite plays alongside other app audio. The latest Assertive sound takes priority; earlier sounds recover when it finishes. Other apps are unaffected.

    seconds remaining

    Use threshold starts unchecked with 13 seconds retained. Check it to enable low-on-time audio. These controls stay in sync with Timer and save automatically; scheduled sessions keep their own choices. Save settings, Ctrl+Enter, or Ctrl+S also saves pending edits.

    Low-on-time audio plays once per session. If a session starts within its threshold, it alerts on its first tick. Ending near zero counts as a normal completion within the threshold, or 15 seconds when Use threshold is unchecked, capped at 10% of the session duration. Time spent is still recorded accurately.

    App sound controls all app audio and matches the Timer slider. Each audio volume below scales this level.

    Voice announcements

    Optional app voice announces start, pause, resume, reset, Timer/Stopwatch switches, Focus on/off, and view changes, including in the tray. Focus buttons and Ctrl+Alt+; use the same feedback. Shortcuts also give guidance when a Focus target is needed, no reflection is available, or an action fails. Routine auto-saves remain silent. Speaks remaining or elapsed time and the reset duration; omits the time at 0:00. Follows App sound volume and plays alongside MP3 audio. View announcements wait for the current timer action to finish; rapid view changes announce only the latest destination. Off by default; saves automatically. Your saved choice is kept on upgrades. Screen readers receive the same messages independently, even with this option off or App sound muted, using their own voice and notification settings.

    Preferred voice: Microsoft Hazel Desktop, speed +3, pitch +20%. If unavailable, uses another installed voice. To get Hazel, install the English (United Kingdom) text-to-speech language feature in Windows Settings → Time & language, then restart this app. The voice package is not bundled.

    Save reflection data

    Logging destinations

    Daily files use MM-dd-yyyy.csv, matching the daily Sheets tab name with filename-safe separators.

    Select either destination or both. CSV is selected by default in Desktop\Reflection Timer Logs; Google Sheets is optional. The folder and daily file are created when an entry is sent. CSV files have column headers and the same response, duration, session status and pause details as Sheets, plus an entry ID to prevent duplicate retries. Test entries use test-MM-dd-yyyy.csv. Open CSV files in a spreadsheet to read the columns as a table; enable Wrap text to show multiline responses and pauses within their cells. Quotes appear only where required to retain the data. CSV files are ordinary readable files. Changing the folder applies to future entries; Retry selected also uses the current folder for a failed CSV entry.

    Startup & diagnostics

    Reflection Timer starts in the tray using your saved settings.

    Save settings

    Ctrl+Enter or the bottom-right Save settings button saves your settings from anywhere on this page.

    The API token, reflections, and drafts are encrypted for your Windows account in %USERPROFILE%\.reflection-timer. This is the single active settings folder for every launch method. Connection settings may be saved incomplete; sending waits until they are valid. Windows sign-in startup is optional and off by default.

    Google Sheets connection

    Your existing desktop connection is retained when upgrading. You can also use the timer and save reflections before connecting to Google Sheets.

    Set up a new Google Sheets receiver
    1. Create or choose your own Google spreadsheet. Enter its URL below.
    2. Choose Save private receiver script. A new token is generated if the token field is blank and none is saved.
    3. In your spreadsheet, open Extensions, then Apps Script. Paste the saved script into the editor and save it.
    4. Run setupReflectionTimer once and authorize it with the Google account that owns the sheet.
    5. Deploy a new web app that executes as you, with access set to Anyone. Copy its deployed URL ending in /exec into the Receiver URL field.
    6. Select Google Sheets under Logging destinations, then choose Save & test connection. The app verifies the receiver before enabling delivery.

    The token protects requests to the receiver. Keep your personalized script and setup code private.

    Leave blank to keep the saved token. No saved token yet.

    Transfer a private connection setup code

    A setup code contains your sheet connection and token. It is not encrypted. Keep it private.

    Diagnostics

    Local event history: timer actions, app focus, schedules, prompt actions, upload outcomes, sleep/resume, and issue markers. No reflection text, credentials, URLs, window titles, or activity from other apps is included in exports. Up to 1,200 events / 7 days.

      Review guide
      
      
      1. Enter a duration, leave the input, and read the surrounding text at your own pace.
      2. Start the timer. Read this page or another app for a minute. The countdown should not interrupt you.
      3. Use Read remaining time. You should hear the current time once.
      4. Open the compact timer and try both views using the keyboard.
      5. Navigate individual Scheduler and Outbox cells using your reader's table commands.
      6. Write a practice reflection, choose Save, and reopen it to check that the draft is preserved.
