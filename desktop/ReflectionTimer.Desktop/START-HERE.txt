Reflection Timer 4.2.10

Stopwatch: Ctrl+Alt+' (apostrophe) switches modes from any app. S/T beside the floating viewer's minus button switches modes, pausing and preserving the other session. App view has a mode switch too. Ctrl+Alt+/ pauses Stopwatch and opens its reflection; Save resumes, Save & send finishes. The Time reached sound defaults to 5 minutes and is editable in Settings below Low on time audio. Receiver 2.9.2 or newer writes C active time, D allotted time (blank for stopwatches), E status, F reason for ending early, and G "timer" or "stop watch". Existing rows stay unchanged. Stopwatch delivery requires 2.9.0+, but the new columns require 2.9.2+. Update your existing Apps Script deployment to a new version using the receiver generated by Connection setup; held entries stay safe in Outbox until retried.

Open ReflectionTimer.exe. Keep the entire application folder together, including Web and the MP3 files.
Microsoft Edge WebView2 Runtime is required. The self-contained package includes .NET.

Upgrading retains the existing desktop profile, Google Sheets connection and preferences automatically.
For a new connection, open Settings and Guided setup. Read START-HERE.html for details.
Close hides App in the tray. Quit desktop app exits. The usual desktop shortcut opens App again.
