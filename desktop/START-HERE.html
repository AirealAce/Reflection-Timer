Reflection Timer 4.2.7

The accessible Windows desktop app keeps your timer, reflections, and Google Sheets connection together.

Open the app

Extract the whole ZIP to a folder and open ReflectionTimer.exe. Keep the Web folder, DLLs, and audio files beside it. Windows x64 is required. The package includes .NET. If prompted, install the Microsoft Edge WebView2 Evergreen Runtime.

Upgrading

The normal app stores encrypted settings in %USERPROFILE%\.reflection-timer, so ordinary and packaged-launcher starts share the same profile. On first launch, your old %LOCALAPPDATA%\ReflectionTimerDesktop profile is copied and verified without deleting the original. Your Sheet, receiver URL, private token, tab routing, saved reflections, schedules and preferences are retained. Quit the previous app before updating. Close hides App in the tray; choose Quit desktop app to exit fully.

Google Sheets

If you already used the desktop app, open Settings to check the saved connection. Test connection uses an authenticated read-only request. For a first installation, use Guided setup to connect a Sheet you own and deploy its Apps Script receiver. Keep the token private. Disable the old Chrome extension before enabling desktop delivery.

Saved reflections wait in the Outbox while delivery is paused or offline. Entries with an uncertain delivery result require review before retrying, to avoid duplicates. Practice reflections use the test tab when connected.

Views and keyboard

App opens centered, Compact at bottom left, and session-end prompts at bottom right by default. App and prompts can remain open with either Compact or Time-only. The floating views share one window. The timer starts at 15 minutes, with low-time warnings enabled at 15 seconds; saved preferences take precedence.

  • Ctrl+Space or Ctrl+Alt+Space: start, resume, or pause from any app while Reflection Timer is running, even with every timer window hidden.
  • Ctrl+Alt+T: show or hide App.
  • Ctrl+Alt+' (apostrophe): switch Timer / Stopwatch, pausing and preserving the current session. Resume the other mode explicitly.
  • Ctrl+Alt+backtick: start/resume or end the session early.
  • Ctrl+Alt+comma: shrink Compact to Time-only, then hide/show.
  • Ctrl+Alt+period: focus Compact; press twice to focus App.
  • Ctrl+Alt+slash: focus the reflection's first text box, or Save and close if either text box is already focused. From elsewhere, reopen a pending reflection or open a check-in; never opens App.
  • Ctrl+Enter or Alt+S in a reflection: send the response and end its own session early if it is still running or paused. Older reflections cannot stop a newer timer. Both skip instead if both fields are completely empty. Ctrl+S saves a local draft and closes, including empty or partially written drafts. Alt+Enter sends a check-in without ending the timer, or skips if both fields are empty.
  • Space or Ctrl+Enter in Compact/Time-only: start, resume, or pause. Ctrl+Enter in App Settings: save settings.
  • Escape in a reflection window: Skip if both boxes are empty, otherwise Save the draft and close.

Completion grace: ending within the session's low-time threshold counts as normal completion. If Low on time audio is unchecked, use 15 seconds instead. Grace is capped at 10% of the allotted duration, and actual elapsed time stays accurate.

Escape hides the focused App view like Ctrl+Alt+T, keeping its selected tab and unfinished edits. The timer and other viewers continue. An open dialog receives Escape first.

Escape in Compact performs the top-right minus action: switch to Time-only and focus the clock. Escape or minus in Time-only hides the floating viewer. Holding Escape performs only one step; the timer continues unchanged.

In reflections, Save keeps a local draft and closes the prompt. Save & send adds the entry to the Outbox for delivery. Bottom-left Prev and Next save locally and browse unfinished reflections, with only one popup visible at a time. Navigation never sends an entry.

Settings includes Auto-send incomplete reflections when a session ends, checked by default. When another session ends, older unfinished session reflections (even blank or closed drafts) enter Outbox marked auto-sent. The new reflection and active check-ins are retained. Turn this off to keep drafts for later review. Practice prompts never send real reflections.

New-user audio defaults: Session end is Assertive, Low on time is Polite, and Success/Failure are Disruptive. Existing audio preferences are preserved.

Use headings, buttons and table commands with your screen reader. The countdown is quiet; Read remaining time announces it on request. If a shortcut is unavailable because another app owns it, Reflection Timer retries automatically.

Your data

Connection credentials, reflections and drafts are encrypted for your Windows account. Keep private setup exports and data backups private. The application download contains no personal Sheets configuration.
